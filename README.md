# Calculator Assistant

A small command-line calculator written in Python. Enter arithmetic with symbols or common phrases such as `5 plus 8` and `square root of 25`.

## Run it

1. Install Python 3.8 or newer.
2. Open a terminal in this folder.
3. Run:

   ```text
   python calculator_assistant.py
   ```

Try these examples when it prompts you:

```text
5 plus 8
12 divided by 3
square root of 25
1126+12
```

Type `quit` or `exit` to close the calculator.

## Supported calculations

Addition, subtraction, multiplication, division, powers, modulo, square roots, absolute values, and rounding. It uses Python's standard library, so no extra packages are needed.

The calculator accepts a limited set of arithmetic words; it does not use an external AI service.
